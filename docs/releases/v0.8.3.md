# simpleHtmlWatch v0.8.3

新增“实验空闲窗口 · 全体汇总”，统计今天 00:00 到当前的历史实验机会，并提供适合汇报的整机紧张情况图。

- 每台资源按连续空闲段分别统计 2 小时、1 小时、半小时、15 分钟、5 分钟五档独立窗口。同档不重叠，各档分别计算；断连、未知、重启缺口不能拼成连续空闲。
- 总览提供工作时段、非工作时段和全天三版，默认工作时段。工作时段统一为每天北京时间 09:00–12:00、14:00–18:00、19:00–21:00；原利用率汇总也同步采用此口径。
- 半小时图分别呈现可用完整窗口、碎片空闲、已观测占用和未观测容量，支持全体与分组、完整 PNG／SVG 图片及五档明细 CSV 导出。同一配置物理资源的多个入口不重复计算容量。
- 首页默认显示 NPU 状态并自动打开总览，不再因存在启用的自定义指令而切换到自定义页面；后台自定义监控继续使用原配置。任务中台专用链接直接进入任务页。
- 复用既有采样，不增加 SSH 轮询。当天状态段记录压缩上限256 KiB，按自然日覆盖，容量裁剪和保存异常明确报告；旧均值无法还原连续段，因此升级前的当天时间显示未观测，不能视为占用。
- 新能力 `daily-idle-windows-v1` 与只读 `/api/availability`，包内 metricsctl 支持 `availability --scope work|off|all`。

升级保留原实例身份、端口、配置、任务、预约、结果与历史；通过内置备份再采用新构建。统计表示已观测到的历史机会，不能保证未来独占，实验前仍需实时核验和预约。详情见 `docs/availability.md`。
