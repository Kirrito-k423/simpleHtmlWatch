# simpleHtmlWatch v0.8.4

实验空闲窗口改为铺满浏览器页面的五图总览，全部节点同时展示，便于直接比较五种实验时长和同组多机机会。

- 2 小时、1 小时、半小时、15 分钟、5 分钟各有独立图；五图并排，每个节点一个方格与圆环，自动适配页面宽高，不再使用滚动长条图。节点顺序在五图中一致，完整图片也包含五图。
- 组网规模提供单机、双机、四机、8机，作用于全部五档。多机仅在明确的同一 B 组内计算，整个窗口固定使用同一批物理节点；未知缺口、排除时段、不同 B 组或中途更换搭档都不能拼接。
- 计数表示互不抢占同一节点的一组保守可行排布，不宣称全局最大值。8 台同时空闲半小时，双机是4次、四机2次、8机1次，不累计所有重叠候选组合。图头显示独立实验次数，节点圆环中心显示参与次数。
- 点击节点可查看五档计数、同组固定成员和北京时间起止。相邻相同成员的窗口合并列出；明细最多每档256段，省略部分明确提示，总数仍包含完整排布。未确认物理身份／唯一B组、同组超过8节点或当天历史分组与当前不符时不借用历史组网。
- 新能力 `simultaneous-idle-windows-v1`；只读 API 和包内 metricsctl 接受 `nodes=1|2|4|8`／`--nodes`。原单机调用保持兼容。

工作／非工作／全天三范围、默认工作时段、首页 NPU 状态及自动打开总览保留。复用已经采集的当天连续段，不新增 SSH 轮询、不改写历史格式、不重新积累新基线。升级沿用内置备份并保留原实例、配置、任务及结果。详情见 `docs/availability.md`。
