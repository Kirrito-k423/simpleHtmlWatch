WORKSPACE SETTINGS

管理机器与共享凭据

01 / 共享凭据

同一用户名和密码只保存一次；机器引用后自动复用。

02 / 机器列表

支持 IP、主机名和自定义 SSH 端口。每屏最多展示 16 台。

03 / 刷新设置

保留 SSH 连接，复用会话定期执行监控命令。

04 / 首次连接

内网调试默认等待 5 秒后自动信任新机器。已保存的密钥变化时仍需手动核对。

密码以加密配置保存在本机。密钥也位于本机配置目录，请妥善保管该目录；导出配置不会包含密码。

批量添加机器

默认开启 NPU 状态、Python 进程和 CPU / 内存。

 


  
确认 SSH 主机指纹
与管理员或机器控制台显示的指纹核对一致后，再信任此机器。
可在机器控制台执行：
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256
请根据服务器实际协商的密钥类型核对相应 .pub 文件。
