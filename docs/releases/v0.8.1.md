# simpleHtmlWatch v0.8.1

新增五档空闲机器排序和有界升级备份，减少选机时反复人工观察及本机多代备份堆积。

- 空闲排序复用已有采样，保存最近6小时的5分钟机器级占用桶（压缩最多64 KiB），启动和北京时间整点/半点覆盖导出 `exports/idle-ranking.json`（最多128 KiB）。网页和两个AI客户端均支持五档、覆盖率、型号/设备数/HBM筛选及当前资源检查。导出文件仅供选候选，领用前仍需实时核验和预约。
- 采用不同构建前自动校验并保存旧程序及核心状态，本机固定一份加密回滚快照和一份当前程序缓存。`-backup-archive-dir` 持久化配置外置归档，最多3份/30天，始终保护最近2份已验证档。磁盘失联保留本机回滚并每30分钟重试；历史资料单独归档，不参加自动淘汰。
- 新增历史资料归档、认证校验和恢复到新目录的维护命令。明确删除来源前执行实际恢复演练及源树比对。AES-256-GCM保护含凭据的备份；钥匙在本机实例目录，须单独安全保管。
- 更新两份独立AI Skill、全局Prompt、Windows安装和恢复文档。发布包不包含凭据、运行状态或恢复钥匙。

升级由唯一维护者核对实例并正常停止准确旧程序，再从新发布目录运行 `-adopt-build`（Windows用 `upgrade.bat`），保持原实例参数。首次从旧版升级不要先覆盖旧二进制。原配置、任务、预约、等待单、清理策略、服务身份和端口保留。5分钟历史从升级后积累，不用旧小时桶补空闲。旧 `ready` 和未指定机器的提交规则保持原定义。

本机运行验证、跨平台CI与实际部署分别验收；模拟SSH和历史候选不能证明真实NPU可用性。完整说明见包内 `docs/idle-ranking.md`、`docs/backup-archive.md`。
