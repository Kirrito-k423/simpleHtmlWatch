# simpleHtmlWatch v0.8.6

实验空闲窗口的五档汇总增加实际数占理论上限的百分比，例如“36 / 295 个 · 12.2%”。零分母显示“—”，PNG／SVG 与 CSV 同步更新。

全体汇总新增日期选择，保留今天加过去7个北京时间自然日，共8日期。每天均支持工作／非工作／全天、五档时长和单／双／四／8机；过去日期按完整自然日，使用当天保留的节点与分组清单。跨午夜观测分别保存，重启读取保留日期。已有当天计数继续使用，旧版本已丢弃的历史明确显示无历史，不用均值估算补齐。

新增只读能力 weekly-idle-windows-v1、date 参数和包内 metricsctl --date。每日期精确历史压缩最多256 KiB，正常8份总计2 MiB，超期日文件自动清理；新目录纳入内置备份。单个历史日损坏保留证据并单独报告，不阻断当天监控。原实例、端口、配置、任务、结果与预算基线保留。
