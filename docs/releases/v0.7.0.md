v0.7.0 限制长期运行的数据增长，并增加网页内快捷 SSH 终端。远程 NPU 实时监控、利用率与占用小时统计、任务调度、资源预约和已有实验结果继续保留。

### 空间控制

- 移除自动结果缓存：任务结束后只保存状态和退出码，下载时从远端经 SSH/HTTP 流式传到用户指定文件。已有本机结果包继续可下载，不自动删除。
- 移除完整命令输出、ps 和进程目录的历史记录与回放入口。
- NPU 小时汇总改用 gzip 日文件，兼容旧 JSON，最多 30 天、总量约 2 MB。
- 任务、预约、等待单和诊断共享持久化的 2 MB 新增预算；重启不会重置。新任务不足额返回 507，原 ID、unknown 占用和预约仍保留。每任务为完成状态预留空间，诊断另设 512 KiB 上限。
- 新增可选 `-bounded-log`，明确指定最多 8 个服务诊断日志，每 30 秒检查，超过 64 KiB 时原位保留末尾 32 KiB；不重启现有 SSH 转发，不适用于实验输出。
- 30 天常驻新增目标为尽量不超过 5 MB，用户主动下载、独立 Agent 和人工备份需另行管理。附带只读的 storage_audit.py，支持不可覆盖基线、分类增量、已观测峰值和采样覆盖检查；合成测试不等于真实运行 30 天。

### 快捷 SSH 终端

- 点击机器卡片 SSH，或顶部 SSH 终端后选择机器，在网页内交互；复用原密码/密钥和已信任主机指纹。
- 支持命令输入、方向键、Ctrl+C 和终端缩放。关闭窗口或 15 分钟无输入断开，不自动重连。
- 最多 4 个终端；浏览器最多 1,000 行回滚，输出逐块确认、不落本机磁盘，资源不足或断开时不会重发命令。
- 终端不预留 NPU。长任务和需要退出码、结果回收的实验仍使用任务中台。

### 升级注意

1. 由维护者核对并正常关闭准确旧实例，保留原数据目录、任务、预约、凭据、主机指纹、锁文件和结果；Windows 使用 upgrade.bat，其他系统显式采用新构建。
2. 服务和随包 Skill 同时更新。新版 wait 等待远端退出结果，随后主动 download 并核验产物；collect 返回 410。
3. 新增能力 bounded-storage-v1、task-result-stream-v1、ssh-terminal-v1。旧构建不能读取 .json.gz 小时日文件，且不遵守预算，不可直接降级。
4. 达到容量上限会拒绝新增写入，保留已有证据；有限空间不承诺无限任务记录。

包含 Windows / macOS / Linux 的 amd64、arm64 包、两个独立 Skill 包、SHA256SUMS 和包结构/架构/凭据排除核验报告。各平台运行测试和浏览器验证见关联 GitHub Actions；跨平台编译本身不代表真实 NPU 环境验收。
