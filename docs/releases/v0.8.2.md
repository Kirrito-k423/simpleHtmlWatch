# simpleHtmlWatch v0.8.2

机器级 NPU 利用率在“全窗口汇总”旁新增“工作时段汇总”和“非工作时段汇总”，便于比较两类时段的平均算力和整机占用。

- 工作时段为每天北京时间 09:00–12:00、14:00–18:00、19:00–20:00，包含开始、不包含结束；其余为非工作时段。每天同样划分，周末与节假日不单独调整。
- 算力和占用分别按各自有效观测时长加权，独立显示覆盖率。今天的覆盖率只计已经过去的对应时段；没有观测时显示缺失，不补成零。三组汇总使用整个查询范围，切换日期视图不改变汇总范围。
- 只读 API 每机器新增 `workingHoursSummary`、`nonWorkingHoursSummary`，返回均值、占用、独立覆盖率、观测秒数及已过去的对应时段秒数。旧全窗口字段保留。
- 直接复用已保存的小时桶，无需等待重新积累历史，不新增 SSH 采样或持久化文件。同步更新利用率说明及包内 AI Skill。

升级由维护者核对准确实例并正常停止旧程序，再从新包运行 `-adopt-build`（Windows 使用 `upgrade.bat`），保持原实例参数。升级自动备份沿用 v0.8.1 的有界加密归档策略；保留原配置、任务、预约、等待单、清理策略、服务身份、端口及历史数据。本版不改变历史日文件格式。
